# Contributing to MirrorCommerce AI

Thank you for your interest in contributing to MirrorCommerce AI.

This project is being developed as a production-quality AI application for the **Perfect Corp. YouCam AI Hackathon** and future commercial development.

Every contribution should follow the project's documentation, architecture and coding standards.

---
## Code of Conduct

Please be respectful and constructive when contributing.

We welcome ideas, suggestions and improvements that align with the project's vision and technical standards.

- Be respectful.
- Write clean and maintainable code.
- Follow the existing project structure.
- Keep discussions professional.
- Focus on solving problems rather than creating unnecessary complexity.
